The escape transport accepts a concrete shell name (or slash-delimited basename)
and a typed operation. For example:

```json
{"op":"escape","shell":"bash","operation":{"method":"quote","string":"a b"}}
```

Success returns `{"ok":true,"value":...}`. `needs_quoting` returns a Boolean;
the other methods return strings. Methods and input fields are:

| Method | Fields |
| --- | --- |
| escape, quote, needs_quoting | string |
| format_path | path |
| env_var | name |
| join | executable, args (array of strings) |
| escape_for_double_quotes | string (PowerShell only) |

PowerShell quote also accepts Boolean `for_exe`; the pinned source ignores its
value. Unknown shells retain the source exception class. Invalid request shapes
fail before dispatch. Formatting delegates to the existing core implementations;
it does not execute a shell or inspect the host environment.

The unchanged shared corpus supplies 12,616 cases across eight shells and six
methods. `supplemental.jsonl` contains 5,984 additional actual Ruby observations:
544 deterministic inputs per PowerShell/tcsh, with extra quote modes and denser
adversarial combinations. These include NUL, Unicode, line separators, control
characters, Windows paths, quotes, dollar signs and command/file options. No
round-trip property is assumed: source quirks remain expected results.

Regenerate the supplement with the existing locked oracle environment:

```sh
BUNDLE_GEMFILE="$PWD/corpus/oracle-ruby/Gemfile" bundle exec ruby tests/escape-wire/capture.rb
```

The generator requires Ruby 4.0.1, the exact oracle commit and lock hash.
`provenance.json` seals the source files, seed, counts and generated bytes.
Rust wire and owned C ABI tests, the standalone Python C consumer, Node, and real
Chromium all execute the shared and supplemental rows. Consumers fail on unknown
operations/applicability or missing rows. Python and JavaScript also verify the
recorded file digests. Split JSONL on LF only: Unicode line separators are data.
